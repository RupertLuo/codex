# Catalyst Codex 文档目录

本目录只记录当前仓库的 fork delta 中仍需要长期维护的 Catalyst 说明、代码边界、同步规则和验证证据。

新增 Catalyst 说明统一放在本目录；`docs/` 的两份既有历史计划偏离见差异索引。`AGENTS.origin.md` 保存官方仓库约定，根目录
`AGENTS.md` 只保存本 fork 的覆盖规则。

## 边界

- 代码继续留在原有 crate；本目录不替代源码、测试、schema 或 release manifest。
- `fork delta` 是相对官方基线的全部变化；`Catalyst patch` 只是其中仍属于产品契约的部分。
- 上游已经提供等价能力时，以删除本地 duplicate、恢复上游实现为目标。
- 数量、提交和测试状态都是可变证据；长期保留规则，不把一次性 handoff 当产品文档。
