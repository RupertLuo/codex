## 5. 如何更新与复核

```bash
git rev-parse rust-v0.149.0^{commit}
git merge-base --is-ancestor rust-v0.149.0 HEAD
git diff --stat rust-v0.149.0 HEAD
git diff --name-status rust-v0.149.0 HEAD
git diff --check
git rev-parse rust-v0.149.0:AGENTS.md
git hash-object AGENTS.origin.md
```

最后两个对象 ID 应一致。下一次更新必须同时更换快照 identity 与统计，不能把旧数字标为“当前 HEAD”。

`git diff --quiet rust-v0.149.0 HEAD -- docs/` 在此快照会返回非零：已有两份历史计划新增，见上表；这不是本次治理引入。新 Catalyst 文档继续归 `docs-cata/`，历史迁移需核对引用后单独处理。
