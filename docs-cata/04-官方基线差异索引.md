在 fork 根目录执行以下命令，可以复现分组，也可用最后一条命令查看完整逐文件差异；不维护容易漂移的逐文件 Markdown 副本。

```bash
python3 - <<'PYCODE'
from collections import defaultdict
import subprocess

base = "3d2ee51ca2d5db578f328aa75e20aa22c0197c9a"
fork = "c591ecb93aa100fffccdd5990643c23dab0c002c"
raw = subprocess.check_output(
    ["git", "diff", "--numstat", "--no-renames", "-z", base, fork], text=True
)
groups = defaultdict(lambda: [0, 0, 0])
for row in filter(None, raw.split("\0")):
    added, deleted, path = row.split("\t", 2)
    parts = path.split("/")
    if parts[0] == "codex-rs":
        group = "构建输入" if len(parts) == 2 else parts[1]
    else:
        group = parts[0] if len(parts) > 1 else "根入口"
    counts = groups[group]
    counts[0] += 1
    counts[1] += int(added)
    counts[2] += int(deleted)
for group, counts in sorted(groups.items()):
    print(group, *counts, sep="\t")
print("TOTAL", *(sum(v[i] for v in groups.values()) for i in range(3)))
```

此快照没有二进制 delta；后续出现 `-` 行数时，应单独计入二进制路径，不将其伪装为零行文本。

在 sibling 布局下，从 fork 根目录运行（Python 3.11+，只读 Git 对象，不运行 Cargo）：

```bash
python3 - <<'PYCODE'
from collections import defaultdict
import subprocess
import tomllib

runtime = "../catalyst-codex-private"
revision = "5bcd93b8ab1bd42ac3c04ad7dc44eb268d27d30f"
def git(*args):
    return subprocess.check_output(["git", "-C", runtime, *args], text=True)

rows = defaultdict(list)
manifest_paths = set()
paths = git("ls-tree", "-r", "--name-only", revision, "crates").splitlines()
for path in paths:
    if path.count("/") != 2 or not path.endswith("/Cargo.toml"):
        continue
    manifest = tomllib.loads(git("show", f"{revision}:{path}"))
    owner = manifest["package"]["name"]
    scopes = [("", manifest), *manifest.get("target", {}).items()]
    for target, scope in scopes:
        for table, kind in [("dependencies", "normal"),
                            ("dev-dependencies", "dev"),
                            ("build-dependencies", "build")]:
            for name, dep in scope.get(table, {}).items():
                if not isinstance(dep, dict):
                    continue
                if not dep.get("path", "").startswith("../../../codex/"):
                    continue
                target_label = f"; {target}" if target else ""
                rows[dep.get("package", name)].append(f"{owner} ({kind}{target_label})")
                manifest_paths.add(path)
for crate, owners in sorted(rows.items()):
    print(crate, "; ".join(sorted(owners)), sep="\t")
print("TOTAL", len(manifest_paths), sum(map(len, rows.values())), len(rows))
PYCODE
```

该脚本针对本快照的直接 path 声明。若后续改为 workspace 继承或改动 sibling 布局，应同步调整解析逻辑，不能把遗漏的声明当作依赖已经删除。

## 基线与原版 Agent 规范核验

```bash
git rev-parse rust-v0.153.4^{commit}
git merge-base --is-ancestor rust-v0.153.4 c591ecb93a
git rev-parse rust-v0.153.4:AGENTS.md
git rev-parse c591ecb93a:AGENTS.origin.md
git hash-object AGENTS.origin.md
git diff --check
```

三个 Agent 内容对象 ID 均应为 `faa57cc0db48123e1011f1eb47692cd3bbbcfc3a`。
下次升级必须同时更新官方身份、fork/Runtime 快照、分组统计和消费清单；不得只替换版本标题，或将固定数字改称“当前 HEAD”。
