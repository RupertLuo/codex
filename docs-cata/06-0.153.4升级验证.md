## 合并热点与适配

| 边界 | 保留的宿主契约 | 接入的上游变化 |
| --- | --- | --- |
| 模型请求 | Runtime policy、HTTP transport、图片迁移、typed baseline 与失效回退 | `access_programs`、session context、Guardian 请求；HTTP incremental 限定普通 Responses Turn，不进入 Guardian |

| TUI | embedded Runtime、模型 readiness、provider onboarding | 异步 catalog 刷新与 view ID；onboarding 使用独立视图，agents overview 遵守 embedded Runtime 门禁 |
| 图片工具 | 原 wire 名称、item 生命周期、固定脱敏日志、历史图片顺序 | `imagegen_request_id: None`、`log_output`、可选 FunctionCallOutput call ID；缺失 ID 不匹配已有调用 |
